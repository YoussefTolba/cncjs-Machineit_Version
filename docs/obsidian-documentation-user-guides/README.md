## Word/A4 Export Notes

Use the page setup in [[00 - A4 Word Formatting Guide]] before pasting or importing these notes into Word.

The notes intentionally use:

- Plain Markdown headings.
- Short paragraphs.
- Simple tables.
- Local image embeds from `assets/`.
- Numbered procedures.
- Standard fenced code blocks.
- No wide images.
- No nested table layouts.

That keeps the content clean in both Obsidian and Word.
